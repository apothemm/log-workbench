# LogWorkbench

![CI](https://github.com/apothemm/log-workbench/actions/workflows/ci.yml/badge.svg)

C# / .NET 10. Утилита для поиска и анализа текстовых логов и JSONL без отправки данных на сервер.

## Возможности

- JSONL с полями `level`, `message` и обычные текстовые строки.
- Фильтр уровня и текста без учёта регистра.
- Статистика по уровням, число повреждённых JSON-строк, ограничение выдачи.
- JSON-отчёт в stdout; исходный файл не изменяется.

## Запуск

```text
dotnet build -c Release
dotnet run -- logs/sample.jsonl --level ERROR --contains timeout
python -m unittest discover -s tests -v
```

## Проверки

GitHub Actions выполняет сборку и тесты. Тесты находятся в исходниках репозитория и работают на временных данных.

## Ограничения

Строки читаются последовательно, но одна очень длинная строка целиком попадает в память. Это анализатор файла, без live-tail. Отчёт включает текст сообщений: проверяйте его перед отправкой.
